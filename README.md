# مدرب العين والجسد والصوت

تطبيق أندرويد عربي يعمل دون اتصال لتدريب الحضور البصري ولغة الجسد والصوت. بُني بـ **Kotlin** و**Jetpack Compose / Material 3** مع بنية طبقية نظيفة وMVVM وHilt وRoom وDataStore مشفر محلياً.

## الميزات التدريبية

- تمرين يومي بلا تكرار، مع فلترة للسياق وتحدي الجمعة.
- ستة برامج جاهزة تعمل دون اتصال: الثقة خلال ٧ أيام، المقابلات خلال ١٤ يوماً، الإلقاء خلال ٢١ يوماً، الحضور والكاريزما خلال ٣٠ يوماً، تحسين الصوت، ولغة الجسد في الاجتماعات.
- لكل يوم برنامج جلسة منظمة تشمل توجيهات للعين والجسد والصوت، وتحدي تسجيل، وتفتح الأيام بالتدرج بعد تقييم الجلسة السابقة.
- تقييم ذاتي خاص بعد كل تسجيل: الوضوح، السرعة، الثقة، الوقفات، مستوى التوتر، وملاحظة شخصية.
- إنجازات أكاديمية محلية: البداية، الصوت الواضح، الثبات، المتحدث، وتحدي الجمعة.
- مكتبة لمواقف واقعية وتمارين متخصصة للعين والجسد والصوت، بما فيها تنبيه صحي واضح لتمرين راحة العين ٢٠-٢٠-٢٠.
- محور **الذكاء الاجتماعي وفن التعامل المسؤول**: ٦٦ بطاقة أخلاقية ضمن ١٢ مساراً يومياً، تشمل التعامل مع الأكبر سنًا، بناء الود، الاحترام، فهم الاحتياج، الإشارات الاجتماعية، الغضب، الرفض، آداب المجالس والحدود؛ مع اختيارات تفاعلية، ٤ أنماط تواصل اختيارية غير تشخيصية، دفعة تواصل يومية، تسجيل ذاتي، وإحصاءات لا تحفظ أي بيانات عن الآخرين.
- **مسارات الحياة والمهارات**: ٣٠ درساً تطبيقياً في الوعي المالي، العلاقات والرعاية المتبادلة، الوعي الذاتي، العادات والانتباه، الإقناع الأخلاقي، إدارة المال الشخصية، والقيادة العملية؛ مع قرار تطبيقي، خطة قصيرة وتأمل محلي لكل درس.

## ملاحظات السلامة التعليمية

- **المال والاستثمار:** الدروس المالية للتثقيف وتنظيم القرار فقط؛ لا تقدم توصيات استثمار أو ضريبة أو ديون، ولا تعد بعائد. تختلف القوانين والظروف، لذا يلزم الرجوع إلى مختص مرخص عند اتخاذ قرار شخصي مهم.
- **العلاقات والرعاية:** أدوات التقدير والإصغاء هي دعوات للحوار وليست تشخيصاً للناس. لا يعني الاهتمام التزاماً، وأي تواصل جسدي يحتاج موافقة صريحة ويمكن سحبها في أي وقت.
- **الانتباه والعادات:** التخيل والحديث الذاتي والتنفس أدوات للتخطيط وتنظيم الانتباه، وليست وعوداً بالتحكم في الواقع أو علاجاً طبياً أو نفسياً.
- **الإقناع والقيادة:** يعرض التطبيق الإقناع الأخلاقي القائم على الوضوح وحرية القرار؛ يمنع الضغط والخداع والاستعجال المصطنع، ويؤكد أن الرفض حق.

## الخصوصية

- لا يطلب التطبيق صلاحية الإنترنت، ولا يستخدم Firebase أو أي خدمة سحابية.
- كل التمارين والسجل والمفضلة محفوظة على الجهاز.
- قيم التفضيلات داخل DataStore مشفرة بـ AES-GCM، ومفتاحها غير قابل للتصدير في Android Keystore.
- تحفظ الملفات الصوتية في `filesDir/recordings` فقط، ويحذف عامل WorkManager الملفات وسجلاتها بعد **٧ أيام**.
- توجد شاشة **خصوصيتك** تعرض الضمانات بوضوح، مع حذف التسجيلات أو السجل أو التقييمات أو بيانات التدريب الاجتماعي أو تقدم مسارات الحياة، أو إعادة التطبيق كبداية جديدة في أي وقت.
- النسخ الاحتياطي للتطبيق معطل.

## المتطلبات

- Android Studio Ladybug أو أحدث، وJDK 17.
- Android SDK Platform 35 وBuild Tools المناسبة.
- هاتف أو محاكي يعمل بـ Android 10 (API 29) أو أحدث.

## التشغيل والبناء

1. افتح المجلد في Android Studio وانتظر مزامنة Gradle.
2. اختر جهاز Android ثم شغّل تكوين `app`.
3. لبناء نسخة التطوير من الطرفية:

   ```bash
   ./gradlew assembleDebug
   ```

4. يوجد APK الناتج في:

   ```text
   app/build/outputs/apk/debug/app-debug.apk
   ```

5. لبناء نسخة الإصدار المصغرة:

   ```bash
   ./gradlew assembleRelease
   ```

## الاختبارات والتحقق

```bash
./gradlew testDebugUnitTest
./gradlew lintDebug
```

تشمل اختبارات الوحدة منطق اختيار تمرين غير مكرر، اختيار تحدي الجمعة، وحذف التسجيلات حسب العمر. قبل نشر نسخة الإصدار، شغّل اختباراً يدوياً لصلاحيات الميكروفون والإشعارات والمنبه الدقيق على Android 12+ وAndroid 13+.

## بنية المشروع

```text
app/src/main/java/com/eyevoicecoach/
├── core/          الواجهة المشتركة، التنسيق، الإشعارات والتنظيف
├── data/          Room، استيراد tips.json، DataStore المشفر والمستودعات
├── domain/        النماذج والعقود وحالات الاستخدام
└── feature/       الرئيسية والتمارين والتسجيلات والإحصائيات والإعدادات
```

ملف التمارين الأولي موجود في `app/src/main/assets/tips.json`. يحوي رقم إصدار؛ يُستورد فقط عند وجود رقم أحدث، وباستخدام إدخال لا يستبدل بيانات المستخدم أو سجله.
