# مدرب العين والجسد والصوت

تطبيق أندرويد عربي يعمل دون اتصال لتدريب الحضور البصري ولغة الجسد والصوت. بُني بـ **Kotlin** و**Jetpack Compose / Material 3** مع بنية طبقية نظيفة وMVVM وHilt وRoom وDataStore مشفر محلياً.

## الخصوصية

- لا يطلب التطبيق صلاحية الإنترنت، ولا يستخدم Firebase أو أي خدمة سحابية.
- كل التمارين والسجل والمفضلة محفوظة على الجهاز.
- قيم التفضيلات داخل DataStore مشفرة بـ AES-GCM، ومفتاحها غير قابل للتصدير في Android Keystore.
- تحفظ الملفات الصوتية في `filesDir/recordings` فقط، ويحذف عامل WorkManager الملفات وسجلاتها بعد **٧ أيام**.
- النسخ الاحتياطي للتطبيق معطل.

## المتطلبات

- Android Studio Ladybug أو أحدث، وJDK 17.
- Android SDK Platform 35 وBuild Tools المناسبة.
- هاتف أو محاكي يعمل بـ Android 10 (API 29) أو أحدث.

## التشغيل والبناء

1. افتح المجلد في Android Studio وانتظر مزامنة Gradle.
2. اختر جهاز Android ثم شغّل تكوين `app`.
3. لبناء نسخة التطوير من الطرفية:

   ```bash
   ./gradlew assembleDebug
   ```

4. يوجد APK الناتج في:

   ```text
   app/build/outputs/apk/debug/app-debug.apk
   ```

5. لبناء نسخة الإصدار المصغرة:

   ```bash
   ./gradlew assembleRelease
   ```

## الاختبارات والتحقق

```bash
./gradlew testDebugUnitTest
./gradlew lintDebug
```

تشمل اختبارات الوحدة منطق اختيار تمرين غير مكرر، اختيار تحدي الجمعة، وحذف التسجيلات حسب العمر. قبل نشر نسخة الإصدار، شغّل اختباراً يدوياً لصلاحيات الميكروفون والإشعارات والمنبه الدقيق على Android 12+ وAndroid 13+.

## بنية المشروع

```text
app/src/main/java/com/eyevoicecoach/
├── core/          الواجهة المشتركة، التنسيق، الإشعارات والتنظيف
├── data/          Room، استيراد tips.json، DataStore المشفر والمستودعات
├── domain/        النماذج والعقود وحالات الاستخدام
└── feature/       الرئيسية والتمارين والتسجيلات والإحصائيات والإعدادات
```

ملف التمارين الأولي موجود في `app/src/main/assets/tips.json`. يحوي رقم إصدار؛ يُستورد فقط عند وجود رقم أحدث، وباستخدام إدخال لا يستبدل بيانات المستخدم أو سجله.
